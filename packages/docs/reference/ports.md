# ポート一覧

各コンポーネントが使用するポートをまとめます。

## 一覧

| コンポーネント    | ポート    | 公開範囲                   | 説明                                  |
| ----------------- | --------- | -------------------------- | ------------------------------------- |
| Frontend（PWA）   | **51730** | ホスト                     | チャット UI                           |
| Agent Core（BFF） | **30010** | ホスト or コンテナ（公開） | REST / SSE の中継                     |
| OpenCode Server   | **40960** | コンテナ内のみ（非公開）   | AI エージェント本体                   |
| Gatekeeper        | **58780** | ホスト                     | ポリシー判定・永続化                  |
| Docs（開発時）    | **51740** | ホスト                     | 本ドキュメントサイト（VitePress dev） |

::: tip
要件定義書の当初値では Gatekeeper が `87880` でしたが、TCP ポートの上限（65535）を超えるため `58780` に修正されています。
:::

## 実行モードごとの構成

| モード                 | Frontend     | Gatekeeper   | Agent Core             | OpenCode                 |
| ---------------------- | ------------ | ------------ | ---------------------- | ------------------------ |
| `pnpm dev`             | ホスト 51730 | ホスト 58780 | ホスト 30010           | ホスト 40960（自動起動） |
| `pnpm start`（Docker） | ホスト 51730 | ホスト 58780 | コンテナ 30010（公開） | コンテナ 40960（非公開） |

## 通信経路

- **ブラウザ → Frontend → Agent Core**: Vite プロキシ / SSE（`/api`）
- **Agent Core → OpenCode**: `http://localhost:40960`（同一ホスト or 同一コンテナ）
- **Agent Core → Gatekeeper**: `http://localhost:58780`（dev）または `http://host.docker.internal:58780`（コンテナ）
- **OpenCode → Gatekeeper**: 直接は通信しない（Agent Core 経由）

## ポート競合時の対応

ポートが使用中の場合、以下の方法で回避できます。

- 使用中のプロセスを特定して終了する
- 環境変数（`PORT` 等）で各サービスのポートを変更する
- 変更後は CORS オリジン設定（`CORS_ORIGIN`）やプロキシ設定も合わせて更新する
