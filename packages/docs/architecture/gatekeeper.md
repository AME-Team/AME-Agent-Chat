# Gatekeeper

`packages/gatekeeper` は **Hono + SQLite** で構成される安全レイヤー兼永続化レイヤーです。ポート 58780 でホスト OS 上で動作します。

## 主な責務

- **ポリシー判定**: ファイル I/O・コマンド実行の許可 / 承認 / 拒否を自動判定
- **永続化**: セッション・メッセージ・設定・承認履歴・トークン使用量を SQLite に保存
- **承認監査**: 全権限要求と判断結果を記録し、履歴として参照可能にする
- **全文検索**: セッションタイトルとメッセージ内容の LIKE 検索

## ポリシーエンジン

エージェントの権限要求は `classify()` で次のように判定されます。

| 条件                                                                 | 判定                 |
| -------------------------------------------------------------------- | -------------------- |
| ホスト OS のシェル・プロセス実行（`execute` 型、シェルコマンド一致） | **拒否（deny）**     |
| パッケージインストール（pip / npm / pnpm / yarn / apt / brew / gem） | **承認（approval）** |
| ワークスペース外へのアクセス（パストラバーサル対策）                 | **承認（approval）** |
| 上記以外のワークスペース内 I/O                                       | **許可（allow）**    |

ワークスペース内外の判定は `resolve()` + `relative()` を使った正規化で行います。

## データベース

SQLite（better-sqlite3 + Drizzle ORM）。データは CWD 非依存の `packages/gatekeeper/data/ame.db` に保存されます。

| テーブル            | 内容                                                   |
| ------------------- | ------------------------------------------------------ |
| `sessions`          | セッション（タイトル・作成/更新日時・ピン留め）        |
| `chat_messages`     | メッセージ（ロール・内容・プロバイダー/モデル/推論量） |
| `app_settings`      | キーバリュー設定（Tier 構成など）                      |
| `approval_requests` | 承認要求と判断履歴（ポリシー判定・理由・結果）         |
| `token_usages`      | トークン使用量とコスト                                 |

起動時に Drizzle マイグレーションを自動適用します。旧バージョンのカレントディレクトリ基準 DB が存在する場合は自動移行します。

## メイン API

| ルート                                | 説明                         |
| ------------------------------------- | ---------------------------- |
| `GET/POST /api/sessions`              | セッションの一覧・検索・作成 |
| `GET/POST /api/sessions/:id/messages` | メッセージの取得・保存       |
| `GET/PUT /api/settings`               | 設定の読み書き               |
| `POST /api/policy/validate`           | パス・コマンドのポリシー判定 |
| `POST /api/approvals`                 | 権限要求の登録と判定         |
| `GET /api/approvals`                  | 未処理 / 履歴の取得          |
| `POST /api/approvals/:id/decision`    | 承認 / 常に許可 / 拒否の記録 |
| `GET/POST /api/usage`                 | トークン使用量の記録・集計   |

## 安全設計

- 本番環境ではエラーレスポンスから内部情報（SQL・パス）を隠します。
- WAL モード + 外部キー制約を有効化。
- `AME_WORKSPACE_ROOT` 環境変数でポリシー判定の基準ディレクトリを指定します。

詳細は [セキュリティ](/architecture/security) も参照してください。
