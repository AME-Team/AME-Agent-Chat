# スラッシュコマンド

チャット入力欄で `/` を入力すると **コマンドパレット** が表示され、矢印キーと Enter で選択できます。

## コマンド一覧

| コマンド    | エイリアス             | 説明                                             | 状態     |
| ----------- | ---------------------- | ------------------------------------------------ | -------- |
| `/new`      | `/clear`               | 新規セッションを開始                             | 利用可   |
| `/sessions` | `/resume`, `/continue` | セッション一覧の表示・切替                       | 利用可   |
| `/models`   | —                      | モデル一覧・切替（Effort プリセットと連携）      | 利用可   |
| `/compact`  | `/summarize`           | セッション履歴を要約圧縮                         | 利用可   |
| `/init`     | —                      | AGENTS.md の作成・更新                           | 利用可   |
| `/export` | — | セッションを Markdown / JSON でエクスポート | 利用可 |
| `/import` | — | エクスポートした JSON からセッションを復元 | 利用可 |
| `/share`    | —                      | セッション共有（Output Prompts 連携）            | 近日対応 |
| `/unshare`  | —                      | 共有解除                                         | 近日対応 |
| `/connect`  | —                      | プロバイダー追加（認証連携）                     | 利用可   |
| `/theme`    | —                      | テーマ切替（ダークモード等）                     | 利用可   |
| `/thinking` | —                      | 思考ブロック表示の ON/OFF 切替                   | 利用可   |
| `/undo`     | —                      | 元に戻す（ファイル変更含む・要 Git）             | 利用可   |
| `/redo`     | —                      | やり直し（`/undo` 後のみ有効）                   | 利用可   |
| `/details`  | —                      | ツール実行詳細の表示切替                         | 近日対応 |
| `/help`     | —                      | ヘルプダイアログ（コマンド・ショートカット一覧） | 利用可   |

## 主なコマンドの詳細

### `/new` と `/clear`

現在のセッションを破棄して、新しいセッションを開始します。`/clear` はエイリアスです。

### `/sessions`

保存済みセッションの一覧を表示し、切り替えます。

### `/compact`

長くなったセッション履歴を要約して圧縮します。コンテキストの肥大化によるコスト増を抑えられます。

### `/init`

リポジトリ直下に `AGENTS.md` を作成・更新します。エージェントが作業する際の指針を定義できます。

### `/export`

現在のセッションを **Markdown** または **JSON** 形式でダウンロードします。

### `/import`

エクスポートした **JSON** ファイルからセッションとメッセージを復元します（詳細は [セッション管理](/guide/sessions)）。

### `/undo` と `/redo`

エージェントによるファイル変更を含む操作を取り消し / やり直します。**Git リポジトリ** 上で利用します。

## 特殊記法

コマンドとは別に、以下の特殊記法が入力で利用できます（[チャット機能](/guide/chat) でも解説）。

| 記法          | 意味                                                |
| ------------- | --------------------------------------------------- |
| `@ファイル名` | ファイル参照。プロンプトに内容を埋め込む            |
| `!コマンド`   | サンドボックスでシェルコマンドを実行（`![` は除く） |

## ヘルプ

`/help` またはキーボードショートカット `?` で、ヘルプダイアログを開けます。コマンド一覧とショートカットを確認できます。
