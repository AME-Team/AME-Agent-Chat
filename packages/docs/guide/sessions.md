# セッション管理

チャットのやり取りは **セッション** という単位で保存・管理されます。サイドバーでセッションを一覧・検索・整理できます。

## セッションを作成する

- サイドバー上部の **新しいチャット** ボタン、または `Ctrl / Cmd + N` で作成します。
- 自分で作成したセッションは、最初のメッセージの先頭 30 文字が自動でタイトルになります。

## セッション一覧の操作

サイドバーでは次の操作ができます。

| 操作     | 方法                                                         |
| -------- | ------------------------------------------------------------ |
| ピン留め | ピンアイコンで固定表示（ブラウザのローカルストレージに保存） |
| リネーム | タイトルをダブルクリックして編集                             |
| フォーク | 複製アイコンで最終メッセージ地点から分岐コピー               |
| 削除     | 削除アイコン（確認ダイアログあり）                           |
| 並び替え | 更新日時 / 作成日時 / 名前で切替                             |

### フォーク（分岐）

セッションをフォークすると、元のセッションを変えずに同じ履歴から新しいセッションを作成できます。
「別のアプローチで試してみたい」ときに便利です。

## 全文検索

サイドバー上部の検索欄に入力すると、**セッションタイトルとメッセージ内容の全文** を対象に検索できます（300ms のデバウンス付き）。検索は Gatekeeper の SQLite に対して実行されます。

## インポート / エクスポート

### エクスポート

`/export` コマンドで、現在のセッションを **マークダウン** または **JSON** 形式でダウンロードできます。

### インポート

`/import` コマンドで、エクスポートした JSON を復元できます。セッションとメッセージが Gatekeeper に保存されます。

## セッションの共有

`/share`・`/unshare` コマンドに対応しています（バックエンド側で実装済み。UI 上は「近日対応」）。

## セッションの永続化

- セッション・メッセージは **Gatekeeper** の SQLite データベース（`packages/gatekeeper/data/ame.db`）に保存されます。
- ピン留め状態や入力履歴などの UI 状態はブラウザのローカルストレージに保存されます。
- アプリを再起動しても会話履歴は保持されます。

::: tip
旧バージョンでカレントディレクトリ基準の `data/ame.db` に保存していた場合、初回起動時に自動で新しい場所へ引き継がれます。
:::
