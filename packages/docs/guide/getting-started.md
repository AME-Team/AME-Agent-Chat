# はじめに

AME Agent Chat は、AI コーディングエージェント [OpenCode](https://opencode.ai) をリッチな Web UI で安全・低コストに運用するための **ローカル開発環境**です。

Windows / Linux / macOS のいずれでも動作し、ブラウザ上でエージェントとチャットしながら、ファイルの編集・コマンド実行・パッケージインストールなどを **承認フロー** で安全に制御します。

## できること

| 機能           | 説明                                                                                                       |
| -------------- | ---------------------------------------------------------------------------------------------------------- |
| チャット       | SSE ストリーミングでリアルタイムに回答を描画。マークダウン・コードハイライト・リンクプレビュー対応         |
| 思考の可視化   | エージェントの思考（reasoning）ブロックとツール実行ログをアコーディオンで確認                              |
| セッション管理 | 複数セッションの作成・リネーム・フォーク・削除、全文検索、JSON インポート / エクスポート                   |
| 承認フロー     | ファイル書き込みなどの操作をポリシーエンジンが自動判定。危険な操作のみ承認ダイアログで確認                 |
| コスト最適化   | タスク内容に応じて high / middle / low の 3 段階のモデルへ自動ルーティング。トークン使用量とコストを可視化 |
| テーマ         | ライト / ダーク / システムの 3 テーマと、5 つのアクセントカラー（Trust Blue 等）                           |
| 多言語         | 日本語 / 英語の UI 切替                                                                                    |

## システム構成

大きく分けて 4 つのコンポーネントと、その背後で動作する OpenCode Server で構成されます。

<SystemLayoutDiagram variant="ja" />

- **Frontend**: チャット UI を提供する React PWA
- **Agent Core (BFF)**: フロントエンドと OpenCode をつなぐ Hono サーバー。LLM ルーター・SSE プロキシ・承認連携を担当
- **Gatekeeper**: SQLite にセッション・メッセージ・設定・承認履歴・使用量を保存し、ファイル I/O のポリシー判定を行う
- **OpenCode Server**: 実際にタスクを実行する AI エージェント本体

詳細は [アーキテクチャ概要](/architecture/overview) を参照してください。
