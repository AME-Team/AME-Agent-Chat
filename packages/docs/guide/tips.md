# 便利な機能と Tips

チャットの活用に役立つ便利な機能やヒントをまとめました。

## 効率化

### ファイル参照でコンテキストを明示する

`@` に続けてファイルパスを入力すると、その内容がプロンプトに埋め込まれます。あいまいな指示よりも、関連ファイルを明示した方が高品質な回答が得られます。

```
@src/router.ts のルーティング処理を最適化して
```

### 素早いコマンド実行

シェルコマンドを手早く確認したい場合は `!` から始まる入力を利用します。

```
!ls src/
!git log --oneline -5
```

### 長い履歴は圧縮する

セッションが長くなりコストが気になる場合は `/compact` で履歴を要約圧縮します。設定の「コンテキストを圧縮する」を有効にすれば自動化できます。

## 安全に使う

### 承認の内容を確認する

「常に許可」を選ぶと同種の操作が以後自動許可されます。特にワークスペース外へのアクセスやパッケージインストールは、内容を確認してから判断しましょう。

### 重要ファイルの変更を監視する

`/undo` は Git リポジトリ上でファイル変更を取り消せます。重要な作業の前にはコミットしておくと安全です。

## 整理と再利用

### セッションのフォークで比較検討

複数の方針を試したいときは、セッションをフォークして並行して試せます。元のセッションは保持されます。

### エクスポートして共有

`/export` でセッションを Markdown や JSON に書き出せます。調査結果の共有や記録に便利です。

### 全文検索で過去の会話を探す

検索欄はタイトルだけでなく **メッセージ内容全体** を対象にします。以前の解決方法を探すのに役立ちます。

## 表示のカスタマイズ

### 思考ブロックの表示切替

エージェントの思考プロセスを確認したい場合は `/thinking` で思考ブロックを表示できます。不要な場合は再実行で非表示にできます。

### ツール実行の詳細

エージェントが呼び出したツールの詳細は「ツール実行」アコーディオンで確認できます。何を編集・実行したのか把握できます。

### ライト / ダーク切替

暗い環境ではダークテーマ、明るい環境ではライトテーマを推奨します。5 つのアクセントカラーから好みのものを選べます。

## トラブルシューティング

### 回答が停止した

- 生成中の **停止ボタン** で中断して、プロンプトを言い換えて再送信してください。
- 入力したメッセージは **編集 & 再生成** で修正できます。

### Agent Core に接続できない

- チャット画面に「Agent Core に接続できません」と表示される場合は、[クイックスタート](/guide/quickstart) の起動手順を確認してください。
- `pnpm dev` は OpenCode Server を自動起動します。手動起動の場合は 40960 番ポートで `opencode serve` が動いていることを確認してください。

### 設定変更が反映されない

- モデル設定はバックエンドで 30 秒間キャッシュされます。少し待ってから再確認してください。
