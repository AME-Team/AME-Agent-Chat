# チャット機能

チャット画面では、OpenCode エージェントとの対話をリアルタイムで行えます。
このページでは入力・表示・編集の機能を詳しく説明します。

## メッセージを送信する

- 画面下部の入力欄にメッセージを入力し、**Enter** で送信します。
- **Shift + Enter** で改行できます（送信されません）。
- エージェントが応答している間は、送信ボタンが **停止（Stop）ボタン** に変わり、クリックすると生成を中断できます。

### 入力アシスト

- **下書きの自動保存**: セッションごとの入力内容が自動保存され、セッションを切り替えても復元されます。
- **入力履歴**: 入力欄の先頭/末尾で **↑ / ↓** を押すと、過去の入力を呼び出せます（セッションごとに最大 20 件）。
- **文字数とトークン目安**: 入力欄の下に文字数と推定トークン数が表示されます（日本語は約 1.5 文字 / トークン、それ以外は約 4 文字 / トークンで推定）。

## 特殊記法

チャット入力では、以下の特殊記法が利用できます。

### `@ファイル参照`

`@` に続けてファイル名の一部を入力すると、ファイル検索のサジェストが表示されます。選択したファイルの内容はプロンプトに埋め込まれ、エージェントに渡されます。

```
このファイルを読んでレビューして: @src/router.ts
```

`@` 参照はポリシー検証を通過したファイルのみ埋め込まれます（詳細は [承認フロー](/guide/approvals)）。

### `!Bash 実行`

先頭が `!`（ただし `![` を除く）で始まるメッセージは、サンドボックス内でシェルコマンドとして実行され、結果がチャットに表示されます。

```
!git status
!ls -la
```

### `/スラッシュコマンド`

`/` で始まる入力にはコマンドパレットが表示されます。詳細は [スラッシュコマンド](/guide/commands) を参照してください。

## 添付ファイル

- ペーパークリップボタン、ドラッグ & ドロップ、クリップボードからの画像貼り付けに対応しています。
- **制限**: 1 ファイルあたり最大 5 MB、同時に最大 4 ファイルまで。

## 回答の表示

### ストリーミング描画

エージェントの回答は SSE でストリーミング配信され、文字単位でリアルタイムに表示されます。生成中は末尾にカーソル記号 `▍` が表示されます。

### マークダウン

- 回答はマークダウンで描画されます（GFM 準拠）。
- テーブル・引用・リスト・画像に対応。
- コードブロックは **シンタックスハイライト** 付きで表示され、言語ラベルと **コピーボタン** が付きます。

### 思考ブロック（Reasoning）

エージェントが内部的に考えた内容は折りたたみ可能な **思考ブロック** として表示されます。表示/非表示は `/thinking` コマンドか、ブロックのクリックで切り替えられます。

### ツール実行ビュー

エージェントがファイル編集やコマンド実行などのツールを呼び出した場合、画面上部に **「ツール実行（N）」** のアコーディオンが表示されます。各ツールの名前・状態・入力内容を確認できます。

### リンクプレビュー

回答内の URL（最大 2 件）は OGP 情報をもとにカード形式でプレビューされます。

## メッセージの操作

各メッセージにカーソルを合わせると操作ボタンが表示されます。

| 操作          | 説明                                                                       |
| ------------- | -------------------------------------------------------------------------- |
| 編集 & 再生成 | 自分が送ったメッセージを編集して送り直します。それ以降の回答は破棄されます |
| プレビュー    | 回答をマークダウンの読み取り専用プレビューで開きます                       |
| ピン留め      | メッセージをピン留めします（ブラウザに保存）                               |
| コピー        | 回答内容をクリップボードにコピーします                                     |

### 長いメッセージの折りたたみ

1500 文字を超える回答は自動的に折りたたまれ、「展開 / 折りたたみ」ボタンで切り替えられます。

## ビューポート操作

- 新しいメッセージが届くと最下部まで自動スクロールします。
- 途中までスクロールして上に戻ると自動追従が止まり、画面右下に **最新へ移動** ボタンが表示されます。

## サイドバーの開閉（Issue #57）

ヘッダー左端の **パネルアイコン** をクリックすると、セッション一覧のサイドバーを開閉できます。閉じた状態ではチャット領域が最大幅で表示されます。開閉状態はブラウザに保存され、次回起動時も維持されます。

## カレントディレクトリの選択（Issue #56）

ヘッダーの **フォルダアイコン**（または現在のディレクトリ表示）をクリックすると、カレントディレクトリ選択ダイアログが開きます。

- **プロジェクト一覧**: OpenCode が認識しているワークスペースから選択できます。
- **任意パス入力**: テキストボックスに直接パスを入力して「選択」を押すこともできます。

選択したディレクトリは Gatekeeper に保存され、次回起動時にも復元されます。切り替えると、そのディレクトリに紐づくセッション一覧が再読み込みされます。

## キーボードショートカット

| ショートカット   | 動作                                                       |
| ---------------- | ---------------------------------------------------------- |
| `Ctrl / Cmd + N` | 新しいチャット（セッション）を作成                         |
| `?`              | ヘルプダイアログを表示（入力欄にフォーカスしていないとき） |

## 接続状態の確認

Agent Core や OpenCode Server に接続できない場合、チャット画面に警告が表示されます。接続状態はヘルスチェック（`/health`）で判定されます。起動方法に問題がある場合は [クイックスタート](/guide/quickstart) を参照してください。
