# 設定（モデル・Tier）

ヘッダー右上のアイコン群から、テーマ・アクセントカラー・言語・モデル設定・使用量などを変更できます。

## テーマと外観

ヘッダーのテーマアイコンをクリックすると、**ライト → ダーク → システム** の順で切り替わります。アイコンは現在の状態（Sun / Moon / Monitor）を表示します。

### アクセントカラー

1 ポイントカラーとして、以下の **5 プリセット** から選択できます。ライト / ダークで異なる値が適用されます（WCAG 2.1 AA 準拠）。

| 名称                 | ライト    | ダーク    |
| -------------------- | --------- | --------- |
| Trust Blue           | `#005B99` | `#3B82C4` |
| Stable Green         | `#2D6A4F` | `#4F8A6E` |
| Grounded Orange      | `#C2410C` | `#DD6B3D` |
| Sophisticated Indigo | `#4338CA` | `#7C79E8` |
| Clarity Teal         | `#0F766E` | `#2FA39A` |

### 言語

ヘッダーの言語ドロップダウンで、**日本語 / English** を切り替えられます。選択に応じて UI フォントも切り替わります（日本語: Noto Sans JP、英語: Noto Sans）。

## モデル選択（ヘッダー）

ヘッダーのモデルドロップダウンから、利用するモデルを **通常どおり選択** できます（Issue #62）。選択したモデルは送信時に指定され、そのモデルで応答が生成されます。

- **Auto（既定）**: モデルを明示指定しません。オーケストレーションを無効（既定）にしている場合は opencode の既定モデルで動作します。

## モデル設定（Tier と Effort）

ヘッダーの「設定」アイコンから **モデル設定ダイアログ** を開きます。ここで LLM の利用戦略をカスタマイズできます。

### LLM オーケストレーション

**「LLM オーケストレーション」** チェックボックス（既定: **オフ**）を有効にすると、モデル未指定時にタスク内容からモデルを自動選択します。オフのままでも、ヘッダーで選択したモデルや opencode の既定モデルで動作します（Issue #62）。

::: tip オーケストレーションとモデル選択の関係
オーケストレーションを有効にすると、ヘッダーのモデル選択は **Auto（既定）** に戻り、タスクに応じた自動ルーティングが優先されます。個別モデルを使いたい場合はオーケストレーションをオフにしてヘッダーから選択してください。
:::

### Tier（3 層モデルティア）

オーケストレーション有効時に、タスクは内容に応じて 3 つのティアのいずれかに自動ルーティングされます。

| ティア | 役割                                                           | 既定モデル（プロバイダー: opencode-go） | 既定の推論量 |
| ------ | -------------------------------------------------------------- | --------------------------------------- | ------------ |
| High   | アーキテクチャ設計・デバッグ・リファクタリングなど高度なタスク | `glm-5.2`                               | Middle       |
| Middle | 一般的な実装・質問（タスク分類のフォールバック）               | `qwen3.7-plus`                          | Middle       |
| Low    | 検索・一覧・ファイル参照などの軽量タスク                       | `deepseek-v4-flash`                     | Low          |

各ティアについて **プロバイダー / モデル / 推論量（Reasoning Effort）** を個別に設定できます。

### 推論量（Reasoning Effort）

推論量は 4 段階から選択できます。

| 値      | 意味       |
| ------- | ---------- |
| High    | 深く考える |
| Middle  | 標準       |
| Low     | 軽量       |
| Nothing | 推論なし   |

### Effort プリセット

「作業の質 × コスト」のバランスを 5 段階のプリセットから選ぶと、全ティアの推論量が一括で設定されます。

| プリセット | High ティア | Middle ティア | Low ティア | 用途                     |
| ---------- | ----------- | ------------- | ---------- | ------------------------ |
| Deep       | High        | Middle        | Low        | 最高品質・じっくり考える |
| Smart      | High        | High          | Low        | 精度優先                 |
| Normal     | Middle      | Middle        | Low        | バランス（既定）         |
| Lite       | Middle      | Low           | Low        | 軽量・低コスト           |
| Rush       | Low         | Low           | Low        | 最速・最安               |

### コンテキスト圧縮

**「コンテキストを圧縮する」** チェックボックス（既定: **オフ**）を有効にすると、送信前に履歴を要約してコンテキストの肥大化を抑えます。コスト削減に有効です。

### チャット幅（Issue #63）

チャットエリア（メインウィンドウ）の横幅を 5 段階のプリセットから選択できます。選択は即時反映され、ローカルストレージに保存されます。レスポンシブ対応のため、小さい画面では各プリセットの `max-w-*` を超えない範囲で最大幅を取ります（狭いプリセットでは画面幅いっぱいにならない場合があります）。

| プリセット | 最大幅                   |
| ---------- | ------------------------ |
| 余白無し   | 制限なし（横幅いっぱい） |
| 広め       | `max-w-5xl`              |
| やや広め   | `max-w-4xl`              |
| 標準       | `max-w-3xl`（既定）      |
| やや狭め   | `max-w-2xl`              |

## 使用量とコスト

ヘッダーの「使用量」アイコンから、プロバイダー × モデルごとの **トークン使用量とコスト** を確認できます。使用量は Gatekeeper に記録されます。

## 通知

ブラウザのフォーカスが外れている間、以下の通知を受け取れます（ブラウザのローカルストレージに保存）。

| 設定             | 既定値                          |
| ---------------- | ------------------------------- |
| サウンド通知     | ON（880 Hz・0.15 秒のビープ音） |
| デスクトップ通知 | ON                              |
| 音量             | 0.6                             |

## 設定の永続化

- モデル設定（Tier / Effort / 圧縮）は **Gatekeeper** の `app_settings` テーブルに保存されます（全セッション共通）。
- テーマ・アクセントカラー・言語・通知設定はブラウザのローカルストレージに保存されます。

::: tip
モデル設定はバックエンドの LLM ルーターが 30 秒間キャッシュします。設定変更がすぐ反映されない場合は、しばらく待つと反映されます。
:::
